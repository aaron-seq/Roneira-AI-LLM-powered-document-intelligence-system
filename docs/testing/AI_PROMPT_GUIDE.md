# AI Prompt Guide

For code or test generation, use the
[engineering reference](../AI_BOOTCAMP_CONTEXT_MASTER.md),
[contribution conventions](../../CONTRIBUTING.md), and
[test strategy](TESTING_GUIDELINES.md).

A useful request identifies the expected behavior, affected entry point,
input/ownership boundaries, existing tests, and acceptance criteria. Ask for
the smallest change and reproducible evidence, including errors, denials,
state invariants, and remaining uncertainty. Do not substitute invented APIs,
unsupported tool lists, or generic completion claims for verification.
